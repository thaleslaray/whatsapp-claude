# Respostas oficiais

Este arquivo é seu. É daqui que a rotina de perguntas do grupo tira as respostas, para não inventar nada e não te perguntar a mesma coisa duas vezes. Escreva do seu jeito; a IA usa o conteúdo, não precisa estar bonito.

Regra de uso para a IA: use só o que está escrito abaixo da linha "As respostas começam aqui". Não acrescente prazo, preço, promessa ou condição que este arquivo não traz. Se a pergunta não estiver coberta, pergunte ao dono. O bloco EXEMPLO não é resposta de ninguém e nunca deve ser usado, mesmo que o assunto coincida.

---

## Como preencher

Um bloco por assunto. A data serve para saber se a resposta ainda vale.

```
## <assunto, com as palavras que as pessoas usam para perguntar>
Atualizado em: AAAA-MM-DD
Resposta: <o que você responde>
Não dizer: <opcional: o que não prometer ou não mencionar>
```
